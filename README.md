# 2-DOF Solar Tracker

A dual-axis solar tracking system developed using MATLAB, Simulink, and Simscape Multibody with PID control.

## Project Overview
This project simulates a solar tracker that adjusts a solar panel's orientation according to the calculated position of the Sun.

## Objectives
- Calculate solar azimuth and elevation angles.
- Model the mechanical tracking system using Simscape Multibody.
- Implement PID control for azimuth tracking.
- Analyze reference and actual azimuth responses.

## Tools & Technologies
- MATLAB
- Simulink
- Simscape Multibody
- PID Controller

## Project Files
- `Solar_Tracker_PersonA.slx` — Simulink model
- `Final Graph.png` — Reference vs Actual Azimuth result

## Results
The simulation compares the reference azimuth with the actual tracker response over a six-hour period. The plotted responses closely overlap, indicating effective azimuth tracking in the simulation.

## Future Scope
- Integrate the elevation tracking axis.
- Improve control response and test different PID parameters.
- Extend the model toward real-time hardware implementation.
